Comp Lifecycle Toolkit

Three standalone tools covering the full arc of a compensation decision — ID the industry, negotiate the target, model the offer.

01

Compensation Intelligence Framework

Model a rough total-compensation value, compare cost of living across cities, benchmark industries on a heatmap, score competing offers, and see which skills carry a pay premium right now.

Use when: you're exploring options before you have a specific offer.
Open tool →
02

Comp Negotiation Tool

Triangulate a defensible salary target from your own sources (or none), compare an offer against your counter on a risk-adjusted basis, practice the conversation, and score your performance.

Use when: you're setting a target and rehearsing before a call.
Open tool →
03

Offer Compensation Planner

Model a real offer letter in detail — startup or corporate, including bonus structure, equity vesting, 401(k) match, and clawback terms with trigger and repayment basis.

Use when: you have a real offer letter in hand.
Open tool →

Using more than one together

Each tool is fully standalone — none of them requires another to be open. When you do want to carry numbers from one to the next, look for the "Handoff" or "Continue to…" box near the bottom of each tool: copy the block it generates, then paste it into the next tool's import box.

Compensation Intelligence Framework → Comp Negotiation Tool ⇄ Offer Planner

Full instructions for each tool, and how the handoffs work, are in the README.
